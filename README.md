# Rubik's Cube: An Application of Group Theory

**A mathematical exploration of the Rubik's Cube through permutations and group theory**

**Authors:** Md Arif Hossain and Chandrani Nag  
**Presentation:** International Conference on Science, Technology, Engineering, Mathematics, and Education (2023), Contributory Talk

## Overview

I first learned to solve the Rubik's Cube by practicing sequences of moves. Later, I became curious about why those moves worked: how could one sequence rearrange certain pieces without disturbing others?

This project explores that question using ideas from group theory. We describe cube moves as permutations and examine how composing moves helps explain the cube's structure and common solving algorithms.

## Mathematical focus

- **Permutations:** A cube move changes the positions and orientations of pieces in a structured way.
- **Composition:** A sequence of moves corresponds to successive transformations.
- **Group theory:** The set of allowable cube transformations provides a concrete way to explore abstract algebraic ideas.
- **Algorithms:** Cube-solving move sequences can be studied as compositions of transformations, not just memorized instructions.

## Presentation and materials

This work was presented as a contributory talk in 2023. The supporting project and presentation files are available in this repository. The presentation should be treated as a conference contribution, not as a peer-reviewed journal article.

## Why this project matters to me

The project helped connect an interest in speedcubing with the mathematics I was studying. It also gave me early practice in explaining an abstract concept through a familiar example.
